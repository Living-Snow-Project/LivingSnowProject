The application requires [Expo development builds](https://docs.expo.dev/develop/development-builds/create-a-build/) for testing.

## Getting Started

1. Follow the instructions for cloning and building the monorepo
2. Create a development build and install it to the device
   1. eas build --platform ios --profile development
   2. eas build --platform ios --profile development
3. Make TypeScript/JavaScript changes and test with 'npx expo start'
